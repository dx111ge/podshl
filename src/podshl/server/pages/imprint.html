Notices about content we mirror


We mirror files that open-source projects publish in their own repositories.
A notice reaches the mirror, never the source: the copy here is withdrawn and
the project returns to unknown — the state of one that never
registered — while everything in the developer's repository is untouched.


Every removal is logged with a public reason code, and the affected party is
told why. That log entry is the statement of reasons. A notice aimed at
a problem class rather than at a specific project is refused, because otherwise
naming somebody else's software could be forbidden by whoever owns the name.
