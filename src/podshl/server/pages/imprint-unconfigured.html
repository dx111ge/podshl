This deployment has no operator identity

It is not a public service. Running one here means a real name and a postal address on the site — that is the address a letter arrives at — and none has been configured. Rather than render an empty box that looks like an imprint, this page refuses.

Set these and restart. All three are required; the register entry is optional and belongs there only if the operator is a registered company.

PODSHL_IMPRINT_NAME       the responsible legal or natural person
PODSHL_IMPRINT_ADDRESS    a postal address that receives post
PODSHL_IMPRINT_EMAIL      an address a person reads

PODSHL_IMPRINT_REGISTER   optional: register number, VAT id
PODSHL_SECURITY_CONTACT   where to report a finding
PODSHL_SECURITY_EXPIRES   when that contact stops being valid (RFC 9116)
PODSHL_NOTICE_CONTACT     where a notice-and-action complaint reaches a person

Nothing here is guessed. Not the hostname, not the address this request arrived at, not a placeholder — a page that invents a legal identity is worse than a page that admits it has none.
